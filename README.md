# منصة الحَسَنَيْن

## الإصلاحات المطبّقة

### 1. مشكلة الخانات في الهيدر ✅
- تم إصلاح تكدّس أزرار التنقل في الشاشات المتوسطة (901-1100px)
- الآن تظهر الأيقونات فقط بدون النص في الشاشات المتوسطة لتوفير المساحة
- يمكن التمرير أفقياً في حال كانت الشاشة ضيقة

### 2. تسجيل Google ✅
- تم إزالة أزرار "الدخول بحساب Google" لأن الميزة تحتاج إعداداً في Firebase
- **لتفعيلها لاحقاً:** في Firebase Console → Authentication → Settings → Authorized Domains، أضف دومين موقعك

### 3. مساعد AI ✅  
- تم إصلاح الاتصال بـ AI ليستخدم Netlify Function بدلاً من الاتصال المباشر
- **لتفعيله:** في Netlify → Site Settings → Environment Variables، أضف:
  - `GEMINI_API_KEY` = مفتاح API من Google AI Studio (مجاني)

## الاستضافة على Netlify
1. ارفع المجلد بالكامل على Netlify
2. أضف متغير البيئة `GEMINI_API_KEY`
3. الموقع سيعمل مع AI تلقائياً
